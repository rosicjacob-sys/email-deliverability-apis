In October, commit `7ac7b60` added an 8-point Readiness Gate (`04-blogs-and-posts.md §4.5`). If ANY of these blockers is red on an **active** blog, Netgrid refuses to generate, publish, retry, or auto-publish!

Look at what the manual says (`04-blogs-and-posts.md §4.1 & §4.5`):
"While any red blocker is open, Generate, Publish, Retry and Suggest all refuse... The banner shows totals ('1,018 × site-profile facts missing')."
That means **even after you top up the AI credits**, any active blog that is missing its 3 local facts, neighbourhood, YMYL organisation byline, or demand queries will **still refuse to publish** until we clear these blockers!

5Why 5,115 Posts Are Stuck "Held for Review" (`Review Queue`)

Understanding Netgrid's Scrubber (`05-seo-review-search-reports.md §5.4`) and how to clear the 5,115-post backlog safely.

  • How the Scrubber Works: Netgrid's quality checker scans every generated draft before publishing. When the Scrubber is set to **`enforce` mode**, any draft that triggers a warning is saved as `status = 'generated'` with `heldForReview = true` instead of publishing to Shopify. When set to **`shadow` mode**, flagged posts publish automatically while logging the warning.
  • Why We Should NOT Blindly Release All 5,115 Held Posts Without Filtering:
    1. Any held post generated for one of the **32 old `.ca` domains** (e.g., `torontopeptides.ca`) has internal CTA links pointing to the dead `.ca` domain!
    2. Any held post generated while **French** was accidentally ticked on an English Ontario/US client (`cooksvillepeptides.com`) is in the wrong language!
    3. Any held post containing phrases like *"without medical supervision"* or human-consumption claims must be dismissed, not released.
  • The Safe 3-Step Purge & Release SQL/Action Plan:
    1. Dismiss** all held drafts on blogs whose language is French outside Quebec (`region <> 'QC'`) or whose text matches `/without medical supervision|human consumption|inject subcutaneously/i`.
    2. Update** `blogs.domain` on the 32 rotated stores FIRST and run **Backfill post tracking** (`04-blogs-and-posts.md §4.10`) so CTA links point to the current active domain.
    3. Release** the remaining clean held drafts in batches (or switch the Scrubber to `shadow` mode once the negative compliance prompt is saved on the `peptides` niche in **Content Studio → Niches**!).
